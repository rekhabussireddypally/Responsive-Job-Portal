# Responsive Job Portal Web Application

A modern and responsive Job Portal Web Application built using HTML, CSS, and JavaScript. The application allows users to search and filter job listings dynamically through an interactive and user-friendly interface.

---

## Live Demo

[View Live Project] https://rekha-job-portal.netlify.app/ 

---

## Project Overview

The Responsive Job Portal Web Application is a frontend-based web project designed to simulate a modern online job searching platform. It provides users with real-time job searching and filtering functionality while maintaining a responsive and visually appealing user interface across desktop, tablet, and mobile devices.

---

## Features

- Responsive and mobile-friendly design
- Dynamic job search functionality
- Filter jobs by location and job type
- Interactive job cards with apply buttons
- Real-time filtering using JavaScript
- Sticky navigation bar
- Smooth scrolling navigation
- Animated job cards and hover effects
- Dynamic job count display
- Empty search result handling
- Cross-device compatibility using Flexbox and media queries
